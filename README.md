# 조선의 위기 디펜스 (초안 v0.1)

초등 사회 5-2 「임진왜란과 병자호란」 기반 협동 디펜스. 갤럭시 탭 가로 화면, 혼자 하기 + 방 코드 온라인 2~4인.

## 구성 파일
| 파일 | 역할 |
|---|---|
| index.html | 게임 전체(이 파일 하나). GitHub Pages 등에 올려서 접속 |
| worker.js, wrangler.toml | 방 코드 릴레이(Cloudflare Workers). 온라인 협동에만 필요 |
| local-relay.js | PC에서 시험할 때만 쓰는 릴레이(`node local-relay.js`) |
| 라운드_출처표.md | 30라운드의 설명·퀴즈·출처(교과서/지도서/보충) 정리 |

## 바로 해 보기
- **혼자 하기**: index.html만 열면 됩니다(인터넷 불필요).
- **온라인 협동**: 아래 1~3단계(한 번만).

## 온라인 배포 3단계
1. **index.html 올리기** — GitHub Pages(기존 방식 그대로).
2. **릴레이 배포** — Cloudflare 계정에서 `npm i -g wrangler` → `wrangler login` → worker.js와 wrangler.toml이 있는 폴더에서 `wrangler deploy`. 끝나면 `https://history-defense-relay.○○.workers.dev` 주소가 나옵니다.
3. **주소 넣기** — 게임 첫 화면 "선생님 설정"에 `wss://history-defense-relay.○○.workers.dev/ws` 입력(이 기기에 저장). 또는 index.html 맨 위쪽 `DEFAULT_RELAY` 값을 바꿔 두면 모든 기기에서 자동 입력됩니다.

방장이 "방 만들기" → 화면의 4자리 코드를 칠판에 쓰기 → 친구들이 "방 입장"에 코드 입력.

## 온라인 배포를 더 쉽게 (GitHub 자동 배포, 선택)
컴퓨터에 아무것도 설치하지 않고 릴레이를 올릴 수 있어요. (이 방법은 아직 직접 실행해 보지 못했어요 — 처음 한 번은 안내대로 따라 하고, 안 되면 알려 주세요.)
1. Cloudflare 계정 만들기(무료) → My Profile → API Tokens → *Edit Cloudflare Workers* 템플릿으로 토큰 만들기. 계정 ID는 Workers 화면 오른쪽에 있어요.
2. GitHub 저장소 → Settings → Secrets and variables → Actions → `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID` 등록.
3. Actions 탭 → **Deploy relay** → Run workflow. 끝나면 배포 로그에 `https://history-defense-relay.○○.workers.dev` 주소가 나와요 → 게임의 "선생님 설정"에 `wss://…/ws` 로 넣기.
4. 방장이 방을 만든 뒤 **🔗 초대 링크 복사**로 보내면, 링크를 연 학생은 방 코드가 이미 들어가 있어요.

## 게임 방식
- 왼쪽 엄지로 영웅 이동(자동 공격), 오른쪽 **소집**(군량으로 무작위 병사) · **함성**(주변 적 기절+피해).
- 같은 병사 2명을 차례로 탭하면 **합성**(최대 4단계). 빈 칸을 탭하면 이동.
- 사전 설명의 **힌트**와 맞는 병종이 더 자주 소집됩니다(게임 규칙이며 역사 사실 주장이 아님).
- 경험치가 차면 **역사 카드** 3장 중 선택(말, 화차, 조총 …). 전투 중간에 **작전 회의**(팀 투표).
- 라운드가 끝나면 **역사 이야기 + 퀴즈**. 정답자 1명당 다음 판 군량 +15.
- 역사에서 패배·후퇴였던 전투는 '시간 벌기'로 표현(결과 화면에서 안내).

## 알아 두기: 한계와 위험, 대응
| 위험 | 대응 |
|---|---|
| 학교 Wi-Fi가 WebSocket을 막는 경우 | 시작 전 교사용 기기 2대로 방 접속 시험. 안 되면 핫스팟 또는 혼자 하기 모드 사용 |

| 교과서 밖 보충 라운드(출처표의 '보충')의 세부 내용 | 수업 전 출처표로 확인·수정. 수치(병력·선박 수)는 자료마다 달라 일부러 넣지 않았음 |
| 난이도가 학급에 안 맞음 | 방장 설정에서 쉬움/보통/어려움, 전투 시간 2·3·5분 선택 |
| 실제 학교 환경에서의 접속·성능 | 아직 실제 갤럭시 탭·학교망에서는 시험하지 못함(아래 참고) |

## 배우자교실 공통 브랜드 (모든 게임 공통)

## 협동전 보상·전설 영웅 (v0.30)
- 협동전 라운드를 이기면 이 기기(localStorage `jd_cw`)에 🎟 뽑기권 + 🧩 전설 조각이 쌓여요. 보상 = 조각 `난이도+미션1`, 뽑기권 `1 + 미션1 + (난이도≥2 ? 1 : 0)`. 결과 id(`G.res.id`)로 한 번만 지급.
- 조각 10개 → 전설 영웅 권율 해금(`LEG`). 해금 뒤 조각은 뽑기권으로 바뀌어요. 새 전설 영웅은 `ROLE`/`START`/`RSP`/`SKILL`/`castSkill`/`HERO_BLURB`/`LEG`에 항목을 추가하면 돼요(그림은 아직 의병 그림을 재사용 + 황금 후광).
- 뽑기(`cwDraw`): 일반 70·희귀 25·전설 5%, 10번째 희귀 이상·30번째 전설 확정, 중복은 조각. 꾸미기 `AUR`는 영웅 발밑 기운(방에 있는 모두에게 보여요).
- 미션: d=이중 전선(기지 2곳, 마감 시간), s=쌍둥이 봉화(두 발판에 다른 영웅이 동시에 서면 게이지), r=속전속결(시간 단축). 협동 난이도 `CLV` 1~3.
- 시험: test/cw29.js(보상·뽑기·보관함 화면), test/cmv29.js(권율·봉화·결과 보상), test/simfull29.js(봇 전체 시뮬레이션: `CL=3 START=2 node ...`)
- 주의: 보상은 기기(브라우저)에 저장되어 기기를 바꾸면 따로예요. 서버에 저장하지 않아 개발자 도구로 고칠 수 있어요(수업용이라 그대로 둠).
